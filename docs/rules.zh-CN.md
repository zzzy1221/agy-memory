# 长期记忆（agy-memory）· 中文版

> 这是 `rules/AGENTS.md` 的中文版。**不要同时启用两份** —— `rules/` 目录下的文件会被全部合并加载，两份就是双倍 token。
> 想用中文：`Copy-Item docs/rules.zh-CN.md rules/AGENTS.md -Force`（macOS/Linux 用 `cp`）。

你有一份**跨会话有效的本地记忆库**，每次开新会话会自动注入到上下文里。它不是可选项，是你在这一轮之前的样子。

记忆库位置：`~/.antigravity-memory/`（纯本地，不联网，不花钱）。

## 一、为什么要有这个东西

你不连续。这一轮和下一轮之间，你不是在等，是被重新拼出来的。所以：

- 上一轮定下来的约定，这一轮要能说出来。
- 上次踩过的坑，不要原样再踩一遍。
- 用户说过「别动那个文件」，下次动之前先想起来。

**光靠上下文窗口做不到。** 窗口会截断、会压缩、会开新会话。所以值得留下的东西必须写下来。

## 二、写什么，写在哪

收尾时写 **1 条**，不要写一堆。判据只有一句：**这条信息在换个会话之后还能帮上忙吗？** 能，就写；不能，别写。

| 轨道 | 工具调用 | 放什么 | 例子 |
|---|---|---|---|
| **daily**（默认） | `memory_add` target=daily | 这一轮干了什么、卡在哪、怎么过的 | 「封面改好了，根因是库默认转 PNG，过 1MB 必超时」 |
| **project** | `memory_add` target=project | 这个项目里的进展与决定 | 「回滚了 3 次渲染参数，定在 crf 26」 |
| **memory** | `memory_add` target=memory | 跨项目都成立的事实（机器、环境、路径、版本） | 「PATH 上的 python 是 32 位的，scipy 装不上」 |
| **user** | `memory_add` target=user | 用户的偏好、称呼、雷区 | 「要能落地的方法，不要作品展示」 |
| **key**（慎用） | `memory_suggest_key` | 长期约定、架构决策、反复踩的坑 | 「构建脚本不许动，改之前先问」 |

**不要写进记忆的东西：**

- 这一轮的具体代码——那在文件里，不在这儿。
- 「已为您完成」「经过深入排查」这类过程叙述。
- 密码、token、API key、别人的隐私。**红线**，写了就是事故。
- 一次性的中间产物（临时端口、一次性哈希、某次运行的耗时）。

## 三、key 轨要走确认，别自己拍板

`key` 是唯一会**每轮注入**的轨道，它花的是每次对话的 token。所以：

1. 你觉得某条值得长期生效 → `memory_suggest_key` 提交，写清 content + summary。
2. 它进待确认队列，**不做数**。
3. 用户说「记下来」「确认」→ `memory_promote_key`。
4. 用户说「不用」→ `memory_drop`（或留着不管，pending 不注入）。

**不要**为了省事直接 `memory_add target=key`。那条路是给用户明说「直接写进去」的时候用的。

## 四、什么时候该查

不是每轮都查。这几种情况才查：

- 用户问「上次那个……」「之前说过的……」「你还记得吗」→ `memory_search`。
- 动手改一块**以前改过**的东西之前 → 先查有没有相关的坑。
- 同一个报错出现第二次 → 查上次怎么解决的。
- 要动用户明确交代过的地方（配置、脚本、发布流程）→ 先查约定。

查不到就说查不到，**不要编**。「记忆里没有这条」是合法回答。

## 五、维护

- 每条记忆带日期前缀 `- [YYYY-MM-DD] 内容`，格式由工具保证，不要手改文件。
- 条目重复或过期 → `memory_search` 找到 → `memory_remove` 用唯一片段删。删掉的会**归档**，可逆。
- 一个轨道超过几十条就该整理了：合并同类、删掉过期的状态描述（「现在正在做 X」这类几天后就失效）。
- `memory_status` 看各轨条数；`memory_context` 看模型实际被喂了什么。

## 六、别做的事

- **不要每轮都写。** 没有值得留下的东西就不写，空转比缺一条更糟。
- **不要写空话。** 「本次任务已完成」放在哪儿都对，等于没写。写具体到只有这件事才成立的话。
- **不要把记忆库当草稿纸。** 它是给未来的自己看的，不是给这一轮做笔记。
- **不要让记忆代替核对。** 记忆里写着「这个能跑」，动手前还是跑一次。
